REST API Endpoints Reference

POST /api/students
Create student record
Requires: name, rollNumber (unique), department, year (1-4).
curl -X POST http://localhost:3000/api/students \
  -H "Content-Type: application/json" \
  -d '{"name":"S. Karthik","rollNumber":"2022cs0014","department":"Computer Science","year":4}'
GET /api/students
Fetch all students (supports ?search= & ?year=)
curl http://localhost:3000/api/students
GET /api/students/:id
Fetch single student by ID
curl http://localhost:3000/api/students/{STUDENT_ID}
PUT /api/students/:id
Update student details
curl -X PUT http://localhost:3000/api/students/{STUDENT_ID} \
  -H "Content-Type: application/json" \
  -d '{"year":4}'
DELETE /api/students/:id
Delete student record
curl -X DELETE http://localhost:3000/api/students/{STUDENT_ID}
